# Issue 26: Reference chip popup: full note chunk text

## What to build

Tapping a `ReferenceChip` opens a dialog displaying the full text of the corresponding source chunk so the user can read the source material.

## Acceptance criteria

- [ ] Tapping a chip opens a `showDialog` modal
- [ ] The dialog displays the full text of the source chunk
- [ ] Dialog has a close/dismiss action
- [ ] Dialog is scrollable if the chunk text is long
